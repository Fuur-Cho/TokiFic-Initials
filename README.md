## 說明

　　從我着手製作TokiFic大系以來，傳統紙張版面的像素化轉譯一直是我的工作重點；因此也有了此次Initials系列的發佈。借助此字體，我們可以在像素對齊環境下實現「首字下沉」的效果（即使因爲像素環境排版軟件的匱乏必須通過空格精確控制）。
  
　　另外，該字體也是我的第一個開源字體系列；文件本體通過IPA協議發佈，可通過此專案獲得；在協議允許的範圍內可以嵌入其他兼容協定的字體中（為了方便準確控制度量作者也鼓勵這樣做）；希望大家的像素排版實驗之旅能夠順利展開。
  
　　現階段已發佈的有16/24px的大寫基本拉丁字母部分；計劃未來形成16/20/24/32/36/40/48/60/64九檔的完整系列，並酌情加入希臘與西里爾字母；歡迎大家使用並提出意見。
